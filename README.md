#WeatherAppAssessment

The WeatherAppAssessment aims to provide the user with the weather forecast of their current location. This app uses the OpenWeatherForecast API
to get the forecast and displays the weather forecast for the next 5 days.

## Features

- Requests permission to acces the users location.
- Displays a forecast for up to five days.
- Shows weather icons from the app assets and temperatures.
- Changes the background(icons from the apps assets) based on the current weather conditions.
- Supports refreshing
- Displays loading and errors.

  ## Requirements

- Xcode with Swift Testing support.
- iOS 17.6 or later.
- OpenWeather API key(Not pushed to the repo).

## Permissions
## Location 

Allow location access when prompted to get users current location.

## Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/ZweliThobile/WeatherAppAssessment.git
   cd WeatherAppAssessment
   ```

2. Open `WeatherAppAssessment.xcodeproj` in Xcode.
3. Select the `WeatherAppAssessment` scheme.
